# uefn-mods
Simple to use Mods to apply to UEFN (Unreal Editor for Fortnite)

## UPDATE:
As of 35.00 the filename is unified, so from now on you will only need to replace the file every update.

# Expose All Tutorial

1. Download the latest UEFN-ExposeAll File.
2. Put that file into your Fortnite Installation's Content Folder, example:
/YourLocation/FortniteGame/Content/
Right there is where you will place it
(usually in the C: Drive Program Files under Epic Games.)

3. Enjoy, your editor should now contain everything that is allowed as a exposed asset, to find these:

Inside of the "Fortnite" folder in the Content Browser, you should find a new folder called "Exposed Content".
This Content can also otherwise be accessed by searching for it like you do in regular UEFN.

# Expose Beta Settings and Unreleased Islands Tutorial

1. Download the "FortniteGame.zip" file and extract the content where your Fortnite is, example:
/YourLocation.

You should already see a FortniteGame folder there, the one from the zip should be merged with that one, if that doesn't happen correctly, just open the zip and drag the "Content" folder into the FortniteGame Folder, same location as the current Content Folder.

2. Now when you launch UEFN, you should see several beta settings as regular settings, there are a few things I purposely kept tagged, here's a list:

- Any Beta Device (pointless to place, they will not validate)
- Custom Video ID Setting on Video Player (pointless to put, it doesn't work without Epic permissions)
- Power Plant Island & Lagoon Island (Both crash upon creation, it's a shame but I can't change it)

Hope you enjoy this mod too!
